## 1 项目概述

### 1.1 项目背景

中南民族大学 ICPC 协会目前采用传统人工管理模式，存在会员数据零散、训练任务不规范、赛事管理混乱、权限管控模糊等问题。本项目旨在构建一套 B/S 架构的协会管理系统，实现会员全生命周期管理、题库资源统一维护、训练任务标准化、竞赛流程线上化、队员能力数据可视化，全面提升协会日常运营与竞赛训练的数字化管理水平。

### 1.2 项目目标

| 目标维度 | 具体指标 |
|---------|---------|
| 功能覆盖 | 覆盖 SRS 定义的 11 个业务模块，MVP 优先交付会员、题库、训练三大核心模块 |
| 系统性能 | 常规操作响应 ≤ 3 秒；支持 ≥ 100 并发用户；OJ 判题响应 ≤ 5 秒 |
| 系统可用性 | 全年可用率 ≥ 95%；训练期和比赛期不安排计划内停机维护 |
| 交付质量 | 所有功能模块通过功能测试和权限测试；代码归档至协会代码库 |

### 1.3 范围边界

**范围内（In Scope）**：
- 11 个业务模块的全部功能（按优先级分阶段交付）
- 与协会自建 OJ 系统双向集成
- 会员分级权限控制
- 系统数据备份与日志审计

**范围外（Out of Scope）**：
- 线下环节（会员大会表决、线下考核、线下颁奖）
- 学校统一身份认证对接（留作后续集成项）
- 协会官网直接对接

### 2.2 技术栈明细

| 分层 | 技术 | 版本 | 选型理由 |
|------|------|------|---------|
| 前端框架 | Vue 3 | 3.4+ | 渐进式、生态成熟、国内社区活跃 |

| 图表库 | ECharts | 5.x | 能力雷达图、训练趋势图展示 |
| 后端框架 | Spring Boot | 3.2+ | Java 生态主流，RESTful 开发高效 |
| ORM | Spring Data JPA / MyBatis-Plus | - | 简化数据访问层 |
| 数据库 | MySQL | 8.0 | 关系型数据存储，成熟稳定 |
| 缓存 | Redis | 7.x | 会话缓存、榜单实时数据缓存 |

## 6 风险与应对

| 风险编号 | 风险描述 | 可能性 | 影响 | 应对策略 |
|---------|---------|--------|------|---------|
| R-01 | OJ 系统接口协议不明确，集成延期 | 中 | 高 | 阶段一优先完成 OJ 接口协议评审，形成接口文档双方确认 |

## 8 验收标准

依据 SRS 4.6，验收按以下维度执行：

| 验收维度 | 验收标准 |
|---------|---------|
| 功能验收 | 逐项对照 SRS 功能模块，100% 高优先级功能通过，中低优先级功能 ≥ 90% 通过 |
| 权限验收 | 所有角色权限控制正确，越权操作被拦截并返回明确错误；权限矩阵覆盖率 100% |
| 性能验收 | 页面加载 ≤ 3s、并发 100 用户稳定、OJ 判题 ≤ 5s、数据查询 ≤ 2s |
| 安全验收 | 密码加密存储（bcrypt/Argon2）；关键操作有日志审计；无高危安全漏洞 |
| 数据验收 | 数据录入、查询、统计准确完整；训练记录、考核成绩、竞赛报名数据无误 |
| 部署验收 | 按部署文档步骤可在全新服务器独立完成部署 |
